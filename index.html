GPA settings

These are starter settings. Change them to match your school's official GPA policy.

Default unweighted scale (4.0): A = 4, B = 3, C = 2, D = 1, F = 0. Plus/minus grades are not separated in this starter scale.

How the calculation works

1. Each course average is calculated from the marking periods you've entered.

2. The average is converted to GPA points using the grade scale below.

3. Weighted GPA adds the selected course-level bonus.

4. Credits are used to calculate a weighted average across courses.

Important: GPA rules vary by school and district. This app starts with a common example scale; it is not an official transcript GPA until you match your school's policy.
